\section{Complete Script Listings}\label{app:listings}

This appendix reproduces, verbatim, every script the reference generators
emit for the smallest depths that exercise every construct: dense
$D = 4$ and sparse $D = 8$. The files are \path{spec/scripts/*.txt} in the
artefact~\cite{layertreerepo}, regenerated by \path{tools/gen_listings.py}
and reflowed for this appendix by \path{paper/reflow_listings.py}; the
paper includes them by reference so that they cannot drift from the code
the test suites execute. Angle
brackets denote pushes of the named constant (\texttt{<TAG\_NODE>} is the
64-byte tagged-hash prefix, \texttt{<EMPTY\_k>} the hash of $\Emp_k$,
\texttt{<ENC0>} the constant $2^{64}$ whose addition implements
\textsf{PAD8}, \texttt{<NUMS>} the BIP-341 nothing-up-my-sleeve point, and
\texttt{<SEL\_*>} the \op{TX} selectors of \S\ref{sec:output}). Bare
integers are minimal number pushes. The byte count in each heading is the
compiled script size. Sizes at $D = 16$ and $D = 32$ are in
Table~\ref{tab:sizes}; each further level adds one \tr{LEVEL} (88 bytes
dense, 135 sparse, 156 MID).
