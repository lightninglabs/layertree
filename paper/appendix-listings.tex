\section{Complete Script Listings}\label{app:listings}

This appendix reproduces every script the reference generators emit, for
the smallest depths that exercise every construct: dense $D = 4$ and
sparse $D = 8$. Tapscript has no subroutines, so a compiled script is one
flat opcode stream; the generators, however, build every script from a
small set of helpers, and the listings below are those streams
\emph{collapsed back} into named macro calls, one per line, with the
remaining raw opcodes wrapped between them. Each tier's macros are defined
once in \S\ref{app:macros-full} to \S\ref{app:macros-min}, themselves
collapsed against the other macros. The collapse is mechanical
(\path{tools/gen_structured.py}) and verified: expanding a structured
listing reproduces the compiled bytes exactly, so these listings and the
flat ones in \path{spec/scripts/} describe the same scripts, and the byte
count in each heading is the compiled size. A run of $n$ identical calls
is written \texttt{NAME x$n$}. Angle brackets denote pushes of named
constants: \texttt{<TAG\_NODE>} is the 64-byte tagged-hash prefix,
\texttt{<EMPTY\_k>} the hash of $\Emp_k$, \texttt{<ENC0>} the constant
$2^{64}$ whose addition implements \textsf{PAD8}, \texttt{<NUMS>} the
BIP-341 nothing-up-my-sleeve point, and \texttt{<SEL\_*>} the \op{TX}
selectors of \S\ref{sec:output}. Bare integers are minimal number pushes.
Sizes at $D = 16$ and $D = 32$ are in Table~\ref{tab:sizes}; each further
level adds one \textsf{LEVEL} (88 bytes dense, 135 sparse, 156 MID).
